## Tech Stack

- **HTML5 / CSS3** — single self-contained file, no build step
- **Vanilla JavaScript** — mobile nav toggle only
- **Fonts** — [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) & [IBM Plex Sans](https://fonts.google.com/specimen/IBM+Plex+Sans) via Google Fonts

Design direction is grounded in a network-monitoring / status-dashboard aesthetic — a nod to the NOC background — with a light paper theme, teal "live" accent, and automatic dark mode based on system preference.

## Features

- Fully responsive layout, down to small mobile screens
- Sticky nav bar with a hamburger menu on mobile
- Light/dark mode (follows OS preference)
- Accessible focus states, reduced-motion support
- Zero dependencies beyond Google Fonts — deploys anywhere as a static file

## Running Locally

No build tools required. Clone the repo and open the file directly, or serve it locally:

```bash
git clone https://github.com/pathaklalitji029/portfolio.git
cd portfolio
python3 -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.

## Deploying

Since this is a single static `index.html`, it can be deployed as-is to:

- **GitHub Pages** — push to a repo and enable Pages on the `main` branch
- **Netlify / Vercel** — drag-and-drop deploy or connect the repo
- Any static host
